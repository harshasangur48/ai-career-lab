AI और Machine Learning में नौकरी तलाश रहे हर fresher का सवाल होता है: *"जब मुझे कोई work experience नहीं है, तो मैं Resume में क्या लिखूं?"*

जवाब बहुत सीधा है: **प्रोजेक्ट्स बनाएं, GitHub पर डालें, और उन्हें Resume में सही तरीके से पेश करें।**

## एक अच्छे Resume के मुख्य हिस्से

### 1. Professional Summary (3-4 पंक्तियां)
ईमानदारी से अपनी स्किल्स और रुचि बताएं:

> *"Final-Year CSE छात्र जो Machine Learning और NLP में विशेषज्ञता रखता है। Python, scikit-learn और TensorFlow का उपयोग करके 5+ प्रोजेक्ट्स बनाए हैं जो GitHub पर उपलब्ध हैं।"*

### 2. Projects Section — सबसे महत्वपूर्ण
हर प्रोजेक्ट में ये तीन बातें जरूर लिखें:
- **प्रोजेक्ट का नाम** और GitHub Link
- **Tech Stack** (उदा. Python, Streamlit, Random Forest)
- **Result / Accuracy** (उदा. 87% Accuracy)

```
उदाहरण:
Loan Approval Predictor — Python, Random Forest, Streamlit
15 वित्तीय डेटा पॉइंट्स के आधार पर लोन अप्रूवल की संभावना predict करने वाला मॉडल।
Accuracy: 87.3% | ROC-AUC: 0.91 | Live Demo Link
```

### 3. Technical Skills
केवल वही स्किल्स लिखें जो आपको वास्तव में आती हैं:
- Languages: Python, SQL
- Libraries: Pandas, NumPy, scikit-learn, Matplotlib
- Tools: Git, GitHub, VS Code, Google Colab

प्रोजेक्ट्स बनाइये और उन्हें अच्छी तरह से समझाइए — नौकरी के अवसर जरूर मिलेंगे।
